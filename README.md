# VK Commander — локальный запуск

1. Создайте отдельное VK OAuth-приложение типа «Веб-сайт».
2. Скопируйте `.env.example` в `.env` и укажите его ID, OAuth-секрет и Redirect URI.
3. В текущем терминале загрузите переменные и запустите сервер:

   ```zsh
   set -a; source .env; set +a
   python3 server.py
   ```

4. Откройте `http://localhost:8000` и нажмите «Получить».

На первом этапе сервер только получает перечень доступных сообществ. Токен живёт только в памяти процесса и не записывается в файлы.
