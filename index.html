Подключение к VK API

Для работы программы необходимо создать приложение ВКонтакте.

  1. Перейдите на dev.vk.com и создайте приложение (тип: Standalone или Website).
  2. В настройках приложения укажите Редирект URI (базовый домен): http://localhost:8000/auth/vk/callback
  3. Скопируйте ID приложения и защищенный ключ и вставьте их ниже.
